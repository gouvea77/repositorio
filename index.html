Sholucro

Painel para afiliados da Shopee acompanharem comissão, pedidos e lucro em tempo real. Cada assinante conecta a própria conta e vê só os próprios números.

  • Sincroniza as vendas com a API de afiliados da Shopee a cada 10 minutos
  • Aviso no Telegram a cada venda e cancelamento
  • Lucro após anúncios, cruzando a comissão com o gasto na Meta
  • Teste grátis, assinatura via Mercado Pago e área de administração
  • Instala no celular como app (PWA) e segue a LGPD, com exclusão de conta
  • Python
  • SQLite
  • API Shopee
  • Telegram Bot
  • Mercado Pago
  • Caddy · HTTPS
